# Weather App 🌤️

A simple and responsive Weather App built using HTML, CSS, and JavaScript. It uses the Visual Crossing Weather API to fetch and display real-time weather information for different cities.

## Features

- Search weather by city name.
- Display current temperature.
- Show weather conditions.
- Display feels-like temperature.
- Show humidity and wind speed.
- Display weather description.
- Toggle temperature between Celsius (°C) and Fahrenheit (°F).
- Handle invalid city names and API errors.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Visual Crossing Weather API
- Fetch API
- Async/Await

## How to Run

1. Clone this repository:

   ```bash
   git clone https://mayanknaruka.github.io/Weather-App/
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser.

4. Enter a city name and click the Search button to check the weather.
